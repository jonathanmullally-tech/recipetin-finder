# RecipeTin Finder

A personal search and filter interface for the public RecipeTin Eats recipe catalogue plus the RecipeTin Eats Dinner cookbook index.

## Publish on GitHub Pages
1. Upload every file and the `icons` folder to the repository root.
2. Settings > Pages > Deploy from branch > main > /(root).
3. Open the Pages URL in Chrome and tap Install app.
4. In the app, tap **Sync recipes**. The app downloads public recipe metadata through RecipeTin Eats' public WordPress API and stores it locally on the device.

The app links back to the official website for the full recipe. Cookbook-exclusive recipes show their book page. Personal favourites, ratings and notes remain on the device.
